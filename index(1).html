Fingerprint-Based Blood Group Detection

A Non-Invasive Approach Using Machine Learning, Computer Vision and Deep Learning

Introduction

Blood group identification is an important part of healthcare, especially during emergency situations, blood transfusions, surgeries, and medical treatments.

Traditionally, blood grouping is performed using a blood sample and laboratory-based serological testing. Although this method is reliable, it requires a blood sample, laboratory materials, trained personnel, and time.

This project explores a different approach: using fingerprint images and machine learning to predict a person's blood group.

Note: This project is a machine-learning research prototype. It is not intended to replace standard clinical blood-group testing or to be used independently for medical decisions.

The Problem

In conventional blood-group detection, a blood sample is collected from the individual and tested using laboratory procedures.

This process can require equipment, reagents, trained professionals, and appropriate healthcare facilities.

In emergency or resource-constrained situations, obtaining and testing a blood sample may not always be convenient. The project therefore investigates whether biometric information, specifically fingerprint patterns, can be used as an additional method for predicting blood group.

Main Research Question

Can machine learning identify patterns in fingerprint images that can be used to predict a person's blood group?

Our Proposed Solution

The proposed system uses fingerprint images as input and applies image processing and deep learning techniques to predict the blood group.

Fingerprint Image → Preprocessing → Gabor Feature Extraction → CNN Model → Blood Group Prediction

The system uses fingerprint images obtained using thermal spectroscopic photoplethysmographic (PPG) sensor technology, extracts relevant features using Gabor filters, and then passes the processed information to a CNN classification model.

How the System Works

1. Fingerprint Image Collection

The first step is obtaining a fingerprint image. The fingerprint contains patterns such as ridges and valleys that can be processed as an image.

2. Image Preprocessing

Before the image is given to the CNN, it is processed to make the important fingerprint patterns more suitable for feature extraction.

3. Gabor Feature Extraction

Gabor filters are used to identify specific patterns and orientations in an image. In fingerprint processing, these filters can help emphasize ridge structures and other local patterns.

4. CNN Classification

After feature extraction, the processed fingerprint image is passed to a Convolutional Neural Network (CNN).

The CNN contains convolution and pooling layers followed by fully connected layers. The final layer uses a softmax-based classification approach to produce probabilities for the blood-group classes.

Training the Machine Learning Model

The dataset is divided into training and testing portions. The implementation uses an 80:20 train-test split.

During training, the CNN learns from fingerprint images associated with their corresponding blood-group labels.

The model is trained using the Adam optimizer and categorical cross-entropy loss.

Performance Metrics

  • Accuracy
  • Precision
  • Recall
  • F1-score

The training process was configured for up to 40 epochs.

Results

Reported Performance

The project reported approximately 97% test accuracy on its dataset.

The application was also tested with fingerprint images representing different blood-group classes.

These results show that the developed model was able to learn useful patterns from the available fingerprint dataset.

The reported result comes from the project's experimental dataset. A larger and more diverse dataset, independent validation, and healthcare-based testing would be required before considering such a system for real-world clinical use.

Web Application

Challenges and Limitations

Dataset Size

A larger and more diverse fingerprint dataset could provide stronger evidence about model performance.

Image Quality

Fingerprint images can vary because of sensor quality, finger position, pressure, noise, and other image-capture conditions.

Generalization

A model that performs well on one dataset may not necessarily achieve the same performance on images collected from a different population or sensor.

Medical Validation

Real-world healthcare deployment would require extensive independent validation, collaboration with healthcare professionals, and appropriate regulatory evaluation.

Future Improvements

1. Larger Dataset

Collect a larger and more diverse dataset of fingerprint images.

2. Advanced Deep Learning Models

Future versions could investigate Transformer-based approaches and hybrid models.

3. Multiple Biometric Inputs

Other biometric information such as palm prints and retinal scans could also be explored.

4. Mobile and Embedded Applications

The model could potentially be optimized for real-time processing and deployment on mobile or embedded devices.

5. Healthcare Validation

Collaboration with healthcare providers could be used to conduct real-world testing and validation.

Conclusion

Fingerprint-Based Blood Group Detection is an exploration of how machine learning and biometric image processing can be combined for blood-group prediction.

The project uses fingerprint images, Gabor filters, and a CNN model to classify eight blood-group categories. A Django web application provides an interface for training the model and performing predictions.

The project reported approximately 97% test accuracy on its dataset, demonstrating the potential of the approach within the experimental setting.

The next step is to build a more robust system through larger datasets, independent testing, real-world validation, improved models, and appropriate healthcare evaluation.
